# Post-confirmatory seed-balanced extension protocol

## Purpose and status

This exploratory extension was specified after the original confirmatory result
and the first post-confirmatory ablation were known. It addresses an imbalance
in that ablation: label smoothing and gaze-only distillation were initially run
only with seed 13, whereas text--gaze distillation used seeds 13, 29, and 47.
The extension does not replace or relabel the confirmatory experiment.

## Symmetric comparison

For each of the three seeds, the final comparison contains the same four
student conditions:

1. the undistilled gaze-only GRU;
2. the same GRU with binary label smoothing, $\epsilon=0.10$;
3. the same GRU distilled from a gaze-only Transformer that receives
   word-level gaze summaries; and
4. the same GRU distilled from the text--gaze Transformer.

The gaze-only and text--gaze teachers are also paired by seed. Every student
uses teacher logits generated by the teacher fitted with that same seed. The
existing seed-13 runs and existing three-seed GRU and text--gaze runs are
retained unchanged. New fits are limited to label smoothing, gaze-only
teachers, and gaze-only students for seeds 29 and 47.

All variants inherit the previously selected learning rate, epoch count, KD
weight, temperature, architecture, and data partitions for their model family.
The retained and new fits use the same PyTorch 2.6.0/CUDA 11.8 software stack
and NVIDIA L40S GPU model. No outer result is used to select a setting.

## Outcomes

For each seed, the analysis reports balanced accuracy and paired differences
for label smoothing, gaze-only KD, and text--gaze KD relative to the GRU. It
also reports the direct text--gaze versus gaze-only contrasts at teacher and
student levels.

The manuscript table uses means over the three matched seeds. Reader-clustered
and crossed reader/article bootstrap intervals apply the same resampled units
to every condition and average the three seed-specific BA differences within
each draw. These intervals quantify sampling variation after averaging the
tested seeds; three seeds do not characterize the full distribution of
optimization outcomes.
